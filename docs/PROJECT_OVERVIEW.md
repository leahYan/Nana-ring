# Project Ring Health: POC Overview

## 1. Executive Summary

The Ring Health system is a Proof of Concept (POC) designed to create a persistent data pipeline for health metrics generated by smart rings. It bridges the hardware data to a private, secure cloud environment (Supabase/Hostinger) for long-term storage and analysis.

## 2. Core Architecture

Refer to `docs/system_architecture.png` for a visual map of the data flow.

- **Mobile Bridge:** Android App (Kotlin) using `libs/ring_sdk_1.0.0.1.aar`.
- **Cloud Backend:** FastAPI (Python) hosted on Hostinger VPS (Docker).
- **Database:** Supabase (Managed PostgreSQL) for time-series data.
- **Frontend:** React + TypeScript dashboard on Vercel.

## 3. Data Flow Philosophy (Offline-First)

1. **Ring -> Phone:** Raw BLE data received by the immutable SDK.
2. **Phone (Room):** Data must be persisted to Room SQLite _immediately_ upon receipt.
3. **Phone -> Cloud:** Scheduled WorkManager tasks flush `pending_uploads` to the FastAPI backend when internet is available.
4. **Cloud (Postgres):** Data is stored permanently in Supabase.
5. **Web (Dashboard):** Fetches historical data from FastAPI for visualisation.
